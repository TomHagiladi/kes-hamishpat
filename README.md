# כס המשפט בעידן המכונה

מצגת ההרצאה של תום הגלעדי בפני שופטי ישראל, במרכז להכשרה ולהשתלמות שופטים.

עותק לצפייה לקהל ההרצאה: השקפים בלבד, בלי הערות המרצה.

- פתיחה: https://tomhagiladi.github.io/kes-hamishpat/
- ניווט: חץ ימינה קדימה, חץ שמאלה אחורה. לחיצה על השקף גם מקדמת.
- במסך צר, כמו טלפון, מומלץ לסובב למצב רוחב.

כל הזכויות שמורות לתום הגלעדי.
